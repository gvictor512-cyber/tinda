## App Name

## Short Description (80 chars max)

## Full Description

**RoomMate Match** es la aplicación revolucionaria que cambia la forma de encontrar compañeros de piso. A diferencia de otras apps que se centran solo en la vivienda, nosotros priorizamos la **compatibilidad humana**.

### 🎯 ¿Por qué RoomMate Match?

**Compatibilidad Inteligente**
Nuestro algoritmo exclusivo analiza múltiples factores para encontrar tu match perfecto:
- Horarios y rutinas diarias
- Nivel de limpieza y orden
- Preferencias sobre tabaco y mascotas
- Rasgos de personalidad e intereses
- Hábitos de convivencia
- Presupuesto y ubicación

**Swipe Interface**
- Desliza hacia la derecha para dar like
- Desliza hacia la izquierda para pasar
- Recibe notificaciones cuando hay match mutuo
- Chat en tiempo real con tus matches

**Verificación Segura**
- Verificación de email y teléfono
- Selfie verification para mayor seguridad
- Sistema de verificación opcional con documento

### ✨ Características Principales

**Matching Avanzado**
- Algoritmo de compatibilidad basado en 9 factores
- Filtros de búsqueda personalizados
- Sistema de likes diarios (gratuito) o ilimitados (premium)
- Ver quién te dio like (premium)

**Chat en Tiempo Real**
- Mensajería instantánea con Socket.io
- Envío de fotos y ubicación
- Notificaciones push para nuevos mensajes
- Chat seguro y privado

**Búsqueda de Pisos**
- Integración con Idealista y Fotocasa
- Busca pisos con tu match
- Guarda favoritos y compártelos
- Filtros avanzados de búsqueda

**Grupos de Convivencia**
- Crea grupos con tus matches
- Calcula compatibilidad grupal
- Busca más miembros para el grupo
