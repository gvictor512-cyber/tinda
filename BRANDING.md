# RoomMate Match - Brand Identity

## App Name
**RoomMate Match** (or **Roomie** for short)

## Logo Design Concept

### Primary Logo
- A modern, minimalist icon combining:
  - A house/home outline (representing living space)
  - Two interlocking puzzle pieces (representing compatibility)
  - A heart shape subtly integrated (representing good relationships)
- Color scheme: Gradient from blue (#4A90E2) to green (#50E3C2)
- Clean, rounded lines for a friendly approachable feel

### Logo Variations
1. **Icon only**: Puzzle-house symbol for app icons
2. **Horizontal**: Icon + "RoomMate Match" text for headers
3. **Vertical**: Icon above text for splash screens

### Color Palette
- **Primary Blue**: #4A90E2
- **Primary Green**: #50E3C2
- **Secondary Purple**: #9B59B6
- **Dark Background**: #1A1A2E
- **Light Background**: #FFFFFF
- **Text Dark**: #2C3E50
- **Text Light**: #FFFFFF
- **Success**: #27AE60
- **Error**: #E74C3C
- **Warning**: #F39C12

### Typography
- **Primary Font**: SF Pro Display (iOS) / Roboto (Android)
- **Headings**: Bold, 700 weight
- **Body**: Regular, 400 weight
- **Captions**: Light, 300 weight

### Tagline
"Encuentra tu compañero de piso ideal"

### Brand Values
- **Compatibility First**: People over properties
- **Trust**: Verified profiles and safe matching
- **Community**: Building better living situations
- **Simplicity**: Easy, intuitive experience
