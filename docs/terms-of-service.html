1. Aceptación de los Términos

Al descargar, instalar o utilizar la aplicación móvil RoomMate Match ("la Aplicación"), usted acepta estos Términos de Servicio ("Términos"). Si no está de acuerdo con estos Términos, no debe utilizar la Aplicación.

2. Descripción del Servicio

RoomMate Match es una aplicación móvil que ayuda a los usuarios a encontrar compañeros de piso compatibles mediante un algoritmo de matching. El servicio incluye:

  • Perfiles de usuario con fotografías
  • Sistema de matching por compatibilidad
  • Chat en tiempo real
  • Búsqueda de propiedades
  • Sistema de verificación de identidad

3.3 Dispositivo Compatible

La aplicación requiere:

  • Android 8.0 o superior
  • iOS 15.0 o superior
  • Conexión a internet estable
