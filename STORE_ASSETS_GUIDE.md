# Store Assets Guide - RoomMate Match

## Required Assets for App Submission

### Google Play Store

#### App Icon
- **Size:** 512x512 px
- **Format:** PNG
- **No transparency**
- **Rounded corners:** No (Google Play adds them automatically)
- **Background:** Solid color or simple gradient
- **Content:** App logo/icon only, no text

#### Feature Graphic
- **Size:** 1024x500 px
- **Format:** JPG or PNG
- **No transparency**
- **Content:** Promotional image showcasing app features
- **Safe zone:** Keep important content away from edges

#### Screenshots (Phone)
- **Minimum:** 2 screenshots
- **Maximum:** 8 screenshots
- **Sizes:**
  - **1080x1920 px** (16:9)
  - **1080x2400 px** (2:1)
- **Format:** JPG or PNG
- **No transparency**
- **Content:** Show different app features

#### Screenshots (Tablet) - Optional
- **Minimum:** 2 screenshots
- **Maximum:** 8 screenshots
- **Sizes:**
  - **1200x1800 px** (2:3)
  - **1200x2400 px** (1:2)
- **Format:** JPG or PNG

#### Promotional Video - Optional
- **Duration:** 30 seconds maximum
- **Format:** YouTube video
- **Resolution:** 1080p or higher
- **Content:** App demo or promotional content

---

### Apple App Store

#### App Icon
- **Size:** 1024x1024 px
- **Format:** PNG
- **No transparency**
- **No rounded corners** (Apple adds them)
- **Flat design:** No shadows or gradients
- **Content:** Simple, recognizable icon

#### App Store Screenshots
- **Minimum:** 3 screenshots
- **Maximum:** 10 screenshots
- **Sizes per device:**
  - **iPhone 6.7" Display:** 1290 x 2796 px
  - **iPhone 6.5" Display:** 1242 x 2688 px
  - **iPhone 5.5" Display:** 1242 x 2208 px
  - **iPad Pro 12.9" Display:** 2048 x 2732 px
  - **iPad Pro 11" Display:** 1668 x 2388 px
- **Format:** PNG or JPEG
- **Content:** Show different app features

#### App Preview Video - Optional
- **Duration:** 15-30 seconds
- **Format:** M4V, MP4, or MOV
- **Codec:** H.264 or ProRes
- **Resolution:** 
  - **iPhone:** 1080p (1920x1080)
  - **iPad:** 2160p (4096x3072)
- **Aspect ratio:** 16:9

## Asset Design Guidelines

### Brand Colors
- **Primary Blue:** #4A90E2
- **Primary Green:** #50E3C2
- **Dark Background:** #1A1A2E
- **Light Background:** #FFFFFF

### Typography
- **Font:** SF Pro Display (iOS) / Roboto (Android)
- **Style:** Clean, modern, readable
- **Size:** Minimum 11pt for readability

### Icon Design
- **Style:** Minimalist, flat design
- **Recognition:** Clear and at small sizes
- **Colors:** Use brand colors
- **Symbol:** House/home icon with people elements

### Screenshot Content
**Required Screenshots:**
1. **Onboarding:** User type selection
2. **Swipe Interface:** Profile matching
3. **Compatibility Score:** Matching algorithm
4. **Chat:** Real-time messaging
5. **Apartment Search:** Integration with rental platforms
6. **Profile:** User profile creation
7. **Premium:** Subscription features
8. **Settings:** Privacy and account settings

**Design Tips:**
- Use real device frames (optional)
- Show status bar with time
- Include device notch (for modern phones)
- Use consistent styling
- Highlight key features
- Add brief text overlays (optional)

## Quality Checklist

### App Icon
- [ ] Correct dimensions (512x512 or 1024x1024)
- [ ] PNG format
- [ ] No transparency
- [ ] No rounded corners
- [ ] High quality at small sizes
- [ ] Follows brand guidelines
- [ ] Recognizable as app icon

### Screenshots
- [ ] Correct dimensions for target device
- [ ] PNG or JPEG format
- [ ] No transparency
- [ ] High resolution
- [ ] Show app features clearly
- [ ] Consistent styling
- [ ] No placeholder content
- [ ] Text is readable
- [ ] No device glitches or bugs visible

### Feature Graphic (Google Play)
- [ ] 1024x500 px
- [ ] JPG or PNG format
- [ ] No transparency
- [ ] Promotes app effectively
- [ ] Brand consistent

## Submission Checklist

### Google Play
- [ ] App icon uploaded
- [ ] Feature graphic uploaded
- [ ] Screenshots uploaded (min 2)
- [ ] Promotional video (optional)
- [ ] Short description (80 chars max)
- [ ] Full description (4000 chars max)
- [ ] Privacy policy URL added
- [ ] Content rating completed
- [ ] Target audience selected
- [ ] Store listing complete

### App Store
- [ ] App icon uploaded
- [ ] Screenshots uploaded (min 3)
- [ ] App preview video (optional)
- [ ] Promotional text (170 chars max)
- [ ] Description (4000 chars max)
- [ ] Keywords (100 chars max)
- [ ] Privacy policy URL added
- [ ] Age rating completed
- [ ] Category selected
- [ ] App review information added
